# Bijdragen aan InlineComp

Leuk dat je wilt bijdragen! Suggesties, bugmeldingen en verbeteringen zijn welkom.

## Hoe

- **Idee of bug?** Open een [issue](https://github.com/Joge10/inlinecomp/issues) met een duidelijke omschrijving (en, bij een bug, de stappen om het te reproduceren).
- **Een concrete wijziging?** Fork de repository, maak een branch, en open een pull request. Beschrijf kort wát je verandert en waaróm.

## Goed om te weten

- De databaseconfiguratie en secrets staan **buiten** deze repository (in `config_inlinecomp.php`, één niveau boven de webroot) en worden niet meegeleverd. De code is daardoor niet zonder meer draaibaar; het is de daadwerkelijke productiecodebase, geen kant-en-klaar pakket.
- Houd de stijl van de omringende code aan — onder andere PDO met prepared statements, vanilla JavaScript zonder framework, en Nederlandstalig commentaar dat het *waarom* uitlegt.

Zo blijft het mogelijk om bijvoorbeeld een aparte afspraak met een partij als de KNSB te maken, zonder dat losse bijdragen dat in de weg zitten.
